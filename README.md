# 論理回路シミュレータ

ブラウザだけで動く、論理回路のシミュレータです。情報Ⅰの授業（たし算する回路・かけ算する回路・命令で動く回路）で使っています。

| ページ | 中身 |
|---|---|
| [index.html](index.html) | 論理回路シミュレータ（AND・OR・NOT、半加算器・全加算器、７セグ・７セグ４桁） |
| [kioku.html](kioku.html) | 記憶つき（Dフリップフロップ・クロック・１回ボタンを追加） |

## 使い方

- 左の部品をクリック → 画面をクリックで置く
- 端子の 〇 をクリック → つなぎたい相手の 〇 をクリックで配線
- 入力スイッチはクリックで 0 / 1
- まちがえたら ［戻す］（Ctrl＋Z）、戻しすぎたら ［進む］（Ctrl＋Y）
- ［真理値表］で、入力の全部の組み合わせと出力を表で見られる（線やゲートをクリックすると途中の 0/1 も出る）
- 回路が大きくなったら ［－］［全体］ で小さく表示（Ctrl＋ホイールでも）
- ［線の色］で、つながっている線ごとに色分け
- 「保存」でファイルに保存、「読み込み」で続きから

## 授業で使うとき

画面上の **［先生に送る］** に、組・番号・先生が言った合言葉を入れてください。
作っている回路が先生の画面に届きます（名前は送りません）。
